Vanishnote

Connect your account (optional)

Without a key, the extension sends quick notes that need no account, like the home page. With your API key, notes go into your dashboard with their activity history, and your team’s policies apply.

  1. Open Settings → Your API key on Vanishnote.
  2. Create a key and paste it here. It’s stored only in this browser profile.

Notes are encrypted in the extension before they’re sent. The key that opens a note is only in its link, and never reaches Vanishnote. Anyone with your API key can create notes as you: revoke it in Settings if it leaks.
